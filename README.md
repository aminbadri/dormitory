# داشبورد مدیریت خوابگاه

نسخه آفلاین و آماده انتشار در GitHub Pages.

## امکانات
- بارگذاری فایل XLSX / XLS / CSV و تحلیل داده‌های واقعی فایل.
- کتابخانه‌های SheetJS و Chart.js داخل پوشه `assets` قرار دارند و وابستگی به CDN ندارند.
- نقشه تعاملی استان‌های ایران به‌صورت داخلی در `index.html` قرار گرفته است و برای نمایش نقشه به اینترنت نیاز ندارد.
- کلیک روی استان، رکوردهای همان استان را با امکان چاپ نمایش می‌دهد.
- کلیک روی شهر در جدول پراکندگی، رکوردهای همان شهر را با امکان چاپ نمایش می‌دهد.
- رنگ استان‌ها بر اساس تعداد رکوردهای فیلترشده تغییر می‌کند.
- شماره ترم تحصیلی بر اساس سال و نیمسال ورود محاسبه می‌شود؛ با سال مرجع ۱۴۰۵ و نیمسال اول: ورود نیمسال اول ۱۴۰۴ = ترم ۳ و ورود نیمسال اول ۱۴۰۳ = ترم ۵.
- هیچ متن تبلیغاتی درباره نحوه پردازش فایل در رابط کاربری نمایش داده نمی‌شود.

## نکته مهم درباره داده
این بسته خودِ فایل اطلاعات دانشجویان را شامل نمی‌شود. پس از باز کردن `index.html` باید فایل Excel/CSV داده‌ها را از بخش بارگذاری انتخاب کنید؛ آمار از داده واقعی همان فایل ساخته می‌شود و آمار نمونه‌ای تولید نمی‌شود.

## استفاده
1. فایل ZIP را استخراج کنید.
2. `index.html` را اجرا کنید یا کل پوشه را در یک مخزن GitHub قرار دهید.
3. فایل Excel/CSV را انتخاب کنید.
4. تطبیق ستون‌ها را بررسی و روی «تأیید ستون‌ها و ساخت داشبورد» کلیک کنید.

## وابستگی‌ها
تمام فایل‌های لازم برای اجرای داشبورد در خود بسته قرار دارند و لینک خارجی برای کتابخانه نمودار، اکسل، فونت یا نقشه استفاده نشده است.
